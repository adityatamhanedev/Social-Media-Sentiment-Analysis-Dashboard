# Social Media Sentiment Analysis Dashboard

## Overview
This project analyzes social media text and predicts sentiment using ML.

## Tech Stack
Python, Scikit-learn, TF-IDF, Streamlit

## Features
- Text preprocessing
- ML model
- Dashboard

## Run
python main.py
streamlit run app/app.py
